## 一、实验目的

本实验旨在验证校园二手交易平台**推荐系统优化方案**的效果，具体目标包括：

1. **验证两级索引优化效果**：对比优化前（无索引遍历全量用户）与优化后（两级索引加速）的推荐接口响应时间
2. **验证降级容错能力**：在 Redis 不可用时，系统能否自动降级到 MySQL 备选方案，保证推荐服务不中断
3. **评估并发处理能力**：在不同并发压力下，系统的吞吐量、响应时间和错误率表现
4. **采集量化性能数据**：为优化方案的效果评估和答辩演示提供数据支撑

## 六、技术方案总结

### 6.1 两级索引优化

**索引结构**：
- 索引1：`idx:category:{categoryId}:users` → Set<userId>
- 索引2：`idx:keyword:{keyword}:users` → Set<userId>

**优化原理**：
- 优化前：遍历全部用户（10万级），逐一计算匹配度
- 优化后：分类索引 + 关键词索引取交集，缩小候选集至数十级别
- 理论加速：10万 / 30 ≈ 3,333 倍

### 6.2 降级容错机制

**L1 降级 — Redis 不可用**：
```
正常链路：Redis → 索引查询 → 匹配计算 → 个性化推荐
降级链路：MySQL → 分类查询 → 按浏览量排序 → 热门推荐
```

**L2 降级 — 新用户冷启动**：
```
正常链路：用户画像 → 匹配引擎 → 个性化推荐
降级链路：MySQL → 全局热门 → 按浏览量排序 → 热门推荐
```
